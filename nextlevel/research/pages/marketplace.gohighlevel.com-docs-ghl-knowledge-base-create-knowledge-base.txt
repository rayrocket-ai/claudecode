Knowledge BaseVersion: v3
Create a new knowledge base (max 15 knowledge bases per location)
POST/knowledge-bases
Try it
Creates a new knowledge base for a location (maximum 15 per location).
WHEN TO USE: use this when you need to add a brand-new knowledge source; use updateKnowledgeBase to rename one; use create (FAQs) or trainDiscoveredUrls to add content.
RETURNS: success and the created knowledge base, including its server-assigned id.
