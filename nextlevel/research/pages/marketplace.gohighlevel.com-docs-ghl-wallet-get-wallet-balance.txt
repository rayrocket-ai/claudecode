WalletVersion: v3
Get wallet balance
GET/wallet/balance
Try it
Fetch the current wallet balance and complimentary credits for the sub-account resolved from the access token.
An Agency token reads the agency wallet, or a named sub-account via locationId. A Sub-Account token always reads its own wallet. Complimentary credits apply to sub-account wallets only and are omitted for an agency read.

locationIdstring
Narrows an Agency token to one of its sub-accounts. Omit it and an Agency token reads the agency wallet. A Sub-Account token may only name its own sub-account: a different one is refused with 403, not ignored.
