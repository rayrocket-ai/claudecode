Get Workflow Definition
GET/workflows/{workflowId}/definition
Try it
Limited availability. The workflow API is currently enabled for selected sub-accounts only; any other sub-account receives 403 WORKFLOW_API_NOT_ENABLED_FOR_LOCATION.
Read a workflow as a complete definition. The definition object is accepted verbatim by Update Workflow Definition, so it round-trips.
The definition's version is the workflow's own counter. Leave it as it comes back: sending it unchanged on update is what stops a concurrent edit in the builder from being silently overwritten.
