Get usage records
GET/wallet/usage-records
Try it
Fetch monthly usage totals for the sub-account resolved from the access token, across the reported window.
Scope follows the access token: an Agency token reads the agency, a Sub-Account token reads its own sub-account. No tenant id appears in the URL.
