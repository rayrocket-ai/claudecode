Create Tag
POST/locations/{locationId}/tags
Try it
Creates a tag in the sub-account. The name is stored lowercased and trimmed, and names are unique ignoring case: creating a name that already exists returns 400.
Authorizations
Authorizationstringheaderrequired
Bearer authentication header of the form Bearer <token>, where <token> is your access token.
Scope:locations/tags.write
Auth methods:OAuthPrivate Integration
Token type:Sub-Account Token
