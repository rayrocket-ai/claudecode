# Course notes template

For Ray's team. Use it while going through any training the team owns.

## How to use it

1. Copy the "Lesson note" block once per lesson.
2. Write in your own words. Do not paste the course's text, slides, templates or scripts into this folder.
3. Keep each note short. One idea per lesson.
4. At the end of each module, move the "What we will copy into Next Level" lines into a task for Ray to approve.

Headings only. Notes go under each one as lessons are completed.
