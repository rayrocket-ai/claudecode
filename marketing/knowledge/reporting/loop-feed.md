# Loop feed

Rewritten every Sunday by the Analytics Loop. The Monday content brief, the content pack and the Daily Video Coach read this before choosing topics.

Status: no data yet. The first Analytics Loop run fills this in.

## Format
- Week covered.
- Make more of: up to 3 topics, formats or hooks, each with the numbers that earned it.
- Make less of: up to 3, with the numbers.
- What brought calls and clients: by source and by post or ad, or "not tracked yet".
- Questions the audience asked this week (themes only).
- One test for next week.
