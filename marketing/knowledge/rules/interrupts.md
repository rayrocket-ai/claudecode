# Interrupts: when an agent stops and hands to a human

Post in Slack #agent-marketing, first line starting with "INTERRUPT:", then one line on what happened and one line on what Ray should do. Never include a phone number, email or full name; use first name and last initial.

| Trigger | What the agent does |
|---|---|
| A person asks for a human | Stop replying. Hand to Ray or Diana the same hour. |
| Angry or upset comment or message | No reply drafted as final. Flag with the text and a suggested calm reply. |
| Risky claim in a draft (price, return, guarantee, "number one", legal or tax advice) | Block the draft, mark "Blocked compliance", say which rule. |
| A post is going viral (well above the account's normal views) | Flag with the numbers and a suggested follow-up piece. |
| Hot lead (timeline under 90 days, pre-approved, or asks for a call) | Flag at once so Ray calls. |
| Unlicensed or trending music in a video | Do not schedule. Ask for licensed audio or original sound. |
| Unsubscribe or "stop" | Never message again. Hand to the CRM owner to confirm removal. |
| Credits or plan quota running low (Higgsfield, ElevenLabs, Metricool, Ad Advisor) | Stop generating. Report what is left. |
| A connector needs sign-in or a tool fails twice | Stop that step, report it in one line, continue the rest. |
